# Fonty

Soubory `*.woff2` v této složce **generuje `scripts/subset-fonts.mjs`** – jsou to
subsety plných TTF z Google Fonts, oříznuté na znaky, které web sází.
Needitovat ručně, přegenerovat skriptem.

| Rodina | Řezy | Autor / zdroj |
|---|---|---|
| Archivo | 400, 700, 800 | Omnibus-Type, https://github.com/Omnibus-Type/Archivo |
| IBM Plex Sans | 400, 500, 600 | IBM, https://github.com/IBM/plex |
| IBM Plex Mono | 400, 500, 600 | IBM, https://github.com/IBM/plex |
